# V Guess the Build

**Minecraft minigame by VACK STUDIO. Product information only.**

V Guess the Build turns a hidden topic into a timed building challenge: one player builds while the others watch, interpret the clues, and submit guesses. Version **1.1.0** organizes play into six independently configured arenas and supports English and Arabic.

## The game

1. Join a waiting arena or let the plugin route you to the least populated one.
2. Choose a topic and build it inside the arena's configured area.
3. Other players watch the build and submit guesses before the round ends.
4. View the results, receive rewards, and continue in another arena.

## Features

- Six separately configured arenas in an operator's existing world.
- Automatic least-populated arena selection, with optional arena selection.
- Spectating for active matches.
- English and Arabic player messages, topics, and saved language preferences.
- Persistent player profiles, rewards, and cosmetic preferences backed by SQLite.
- Player state restoration when leaving a match or reconnecting.
- Configurable build regions; no world or prebuilt map is part of this project page.

## Verification status

The 1.1.0 build completed with 8 automated tests passing. The four packaged YAML files parsed, and 245 English/Arabic message entries were checked. A disposable live Paper server was not run, so multi-arena lifecycle and connected-client gameplay still need staging verification.
